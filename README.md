# 知园 MindGarden

一个参考 [Andrej Karpathy 的 LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 理念的个人知识管理网站。

**产品主张：让收藏的资料，长成自己的知识。**

## 项目概览

知园把个人知识管理组织成一个闭环：**收集资料 → 编译知识 → 建立关联 → 引用问答 → 回存探索 → 维护知识**。

- 可操作的完整前端原型，预置 12 个知识页和 8 份原始资料。
- 编辑、搜索、收藏、双向链接、图谱探索和数据备份均已实现。
- 使用浏览器本地存储，无第三方运行依赖，也无需 API 密钥。
- 编译和问答使用明确标注的 mock 规则，展示系统设计与交互流程。
- 16 项数据与流程检查通过；真实浏览器视觉验收尚未完成，详见 [验证报告](./验证报告.md)。

## 直接体验

无需安装：下载 [MindGarden.html](./MindGarden.html)，再用 Chrome 或 Edge 打开本地文件。CSS、示例数据和应用逻辑已内嵌，离线也能使用。不要通过会禁用 JavaScript 的文件预览器打开。

源码入口：`dist/index.html`。整个 `dist/` 可以作为静态站点部署。

开发模式需要 Node.js 20+，不依赖第三方包：

```sh
npm run dev
```

打开终端显示的 `http://127.0.0.1:4173`。使用 `npm run check` 做 JavaScript 语法检查。

## 五分钟演示路线

1. 在首页浏览四项真实计算的统计，切换「最近更新 / 我的收藏 / 关联最多」。
2. 打开「资料收件箱」，选择「如何让阅读真正变成输出？」。查看原始笔记，点击「编译为知识」。
3. 在编译预览中修改标题、勾选关联的知识，确认编译。进入新知识页，检查侧栏的原始来源、正向链接和反向链接。
4. 编辑知识页，用 `[[第二大脑]]` 添加已有知识引用。保存后，点击链接跳转，再收藏或导出 Markdown。
5. 在图谱中点击不同节点，拖动空白处移动、放大缩小，查看每个节点的上下文。
6. 在「问问知识库」尝试「RAG 和 LLM Wiki 有什么区别？」。核对引用，将答案存为知识页，然后在知识库中找到它。
7. 在「知识维护」为「渐进式披露」补充原始来源。也可以创建一个独立知识页，观察孤立页面检查。
8. 在设置中导出完整 JSON 备份；导入时先查看预览，再确认恢复。

## 实现思路

### 对 LLM Wiki 的映射

- **Raw**：`sources` 保存不可变的原始文本、链接、作者和收集日期。
- **Wiki**：`pages` 保存整理后的 Markdown、来源 ID、关联知识 ID、标签和更新时间。
- **Schema**：前端数据约定与维护规则定义页面结构和引用关系。
- **Ingest**：收集 → 预览提炼 → 确认 → 更新知识及关联。
- **Query**：搜索已整理知识 → 展示带引用摘要 → 有价值的探索回存 Wiki。
- **Lint**：检查结构质量，不擅自替用户判断事实真伪。
- **Index / Log**：知识库作为索引，操作日志记录收集、编译、编辑、提问和维护。

### 技术选择

原生 HTML / CSS / JavaScript，不需要构建和安装。使用 hash 路由，SVG 图谱、事件委托、轻量 Markdown 渲染和浏览器本地存储。页面、资料和关系用稳定 ID 连接；图谱和反向链接从关系数据实时计算。

用户输入在渲染时转义，网页资料仅接受 HTTP(S) URL。导入备份检查版本、字段类型、ID、日期、数组上限与重复 ID；浏览器存储失败时回滚到最后一次保存的数据并提示。

桌面采用固定导航与内容区；小屏使用抽屉菜单、两列知识卡片与单列阅读布局。色彩以纸白、森林绿和少量暖橙为主，强调知识花园的持续生长感。

## Mock 与真实能力边界

- 资料收集、编辑、搜索、关系计算、收藏、导入导出、持久化和结构维护是真实实现。
- **编译不是 LLM**：按分句规则提炼正文并用标签建议关联，不执行语义推理。
- **问答不是 LLM**：按中英文关键词和中文二元词匹配已有知识，组合摘要；界面明确标为 mock。
- 网页导入需要粘贴正文，不自动爬取链接。
- 只支持 TXT / Markdown 文本文件，不解析 PDF、Word 或图片。
- 示例笔记是演示摘要，不是外部网站完整原文。
- 数据仅保存在当前浏览器，不跨设备同步。`file://` 下的存储支持取决于浏览器；若提示存储不可用，请使用静态 HTTP 服务。
- 维护不自动验证事实，不自动判断观点冲突或过期信息。

真实 LLM 扩展可在服务器增加受保护的编译 / 问答接口，要求结构化输出、来源引用和更新预览；API 密钥保留在服务端。进一步可增加持久数据库、对象存储、用户登录和版本历史。
